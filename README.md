# DataCleaner (数据清洗整理工具 v2.0)

> 基于纯 C 语言与原生 Win32 API 打造的高性能、轻量级、免运行环境的表格数据批量清洗整理工具。

[![Language](https://img.shields.io/badge/Language-C11-blue.svg)](https://en.wikipedia.org/wiki/C11_(C_standard_revision))
[![Platform](https://img.shields.io/badge/Platform-Windows-0078D6.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 🌟 核心特性

- **极致性能与极低内存**：纯 C 语言编写，底层采用基于流式解析的 `xlsxio_read` 和高速写入的 `libxlsxwriter`，万级行列表格秒级处理，不爆内存。
- **真正零依赖运行**：静态编译为原生 Windows 独立可执行文件（约 2MB），**无需安装 Python、Java、.NET Framework，亦无需本地安装 Microsoft Office / WPS**。
- **多格式多编码支持**：
  - 支持 `.xlsx`（Excel 2007+ 格式，支持多 Sheet 读取与写入）。
  - 支持 `.csv` 格式（智能适配 UTF-8 及 ANSI/GBK 编码，支持带引号与换行字段）。
- **批量与便捷操作**：
  - 支持批量添加文件、扫描导入整个目录（自动递归子文件夹）。
  - 支持将文件或文件夹直接**拖拽 (Drag & Drop)** 到界面导入。
  - 支持双击列表项快速移除、一键清空列表。
- **安全与防丢**：始终采用另存为机制，自动在原文件名后追加 `_Cleaned`，绝不篡改或覆盖用户原始文件。
- **现代化桌面交互**：
  - 界面支持自由拉伸与全屏最大化，控件自动平滑排版。
  - 多线程后台清洗，UI 界面流畅不卡死，实时刷新百分比进度条与多行运行日志。
  - 支持运行过程中**随时取消**任务。
  - 自动记忆上一次使用的清洗模式及配置（保存至系统注册表）。
  - 清洗完成后提供一键“打开输出目录”和“打开结果文件”快捷入口。

## 🛠️ 九大专业清洗模式

| 模式名称 | 作用说明 | 典型场景 / 示例 |
| :--- | :--- | :--- |
| **数字提取（拼接输出）** | 智能抽取单元格内的所有正数、负数及小数，使用自定义分隔符（如 `,`、`/`、空格等）串联输出；未找到数字则保留原样。 | `"合计: 12.5元, 折扣-3"` ➔ `12.5, -3` |
| **数字求和** | 提取单元格中的全部数值并计算总和。 | `"A款 100 件, B款 250 件"` ➔ `350` |
| **数字求乘积** | 提取单元格中的全部数值并计算累乘积。 | `"长 12.5 * 宽 4"` ➔ `50` |
| **数字平均值** | 提取全部数值并计算算术平均值。 | `"第1次:80 第2次:90"` ➔ `85` |
| **数字最大值** | 提取全部数值并取最大值输出。 | `"报价: 15, 30, 25"` ➔ `30` |
| **数字最小值** | 提取全部数值并取最小值输出。 | `"报价: 15, 30, 25"` ➔ `15` |
| **数字个数统计** | 统计单元格中包含的有效数字数量。 | `"编号 101, 102, 103"` ➔ `3` |
| **文本清理** | 去除首尾空白、全角标点与字符转半角、合并多余连续空格、过滤换行与控制字符。<br>*(可选激进模式：仅保留汉字、字母、数字及空格，剔除所有特殊符号)* | `"　测试 　ABC \r\n "` ➔ `"测试 ABC"` |
| **日期标准化** | 智能识别多种常见中英文日期/时间格式，统一转换为规范的 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM:SS`。<br>支持格式如：`2024-1-1`、`2024.01.01`、`2024/1/1`、`20240101`、`2024年1月1日` 等。 | `"2024.5.1 8:30"` ➔ `2024-05-01 08:30:00` |

## 🚀 编译与构建

项目使用 **MSYS2 (UCRT64)** 环境与 GCC 进行编译。

### 1. 环境准备

安装 [MSYS2](https://www.msys2.org/) 并打开 **MSYS2 UCRT64** 终端，安装编译工具链和相关静态库：

```bash
pacman -S --needed \
    mingw-w64-ucrt-x86_64-gcc \
    mingw-w64-ucrt-x86_64-make \
    mingw-w64-ucrt-x86_64-libxlsxwriter \
    mingw-w64-ucrt-x86_64-libxlsxio \
    mingw-w64-ucrt-x86_64-libzip \
    mingw-w64-ucrt-x86_64-expat \
    mingw-w64-ucrt-x86_64-zlib \
    mingw-w64-ucrt-x86_64-bzip2 \
    mingw-w64-ucrt-x86_64-xz \
    mingw-w64-ucrt-x86_64-zstd
```

### 2. 编译可执行程序

进入项目根目录执行 `make`：

```bash
make
```

编译成功后将在根目录生成 `DataCleaner.exe`。

如需清理编译生成的中间文件：

```bash
make clean
```

## 💡 使用步骤

1. **导入文件**：
   - 点击 **“添加文件”** 选择单个或多个 `.xlsx` / `.csv` 文件；
   - 或点击 **“添加目录”** 自动扫描选中文件夹下的所有支持表格；
   - 亦可直接在资源管理器中选中文件/文件夹拖拽入窗口。
2. **选择规则**：
   - 在下拉框中选择所需的清洗规则；
   - 若选择“数字提取”，可自定义分隔符（默认为英文逗号加空格 `, `）；
   - 若选择“文本清理”，可按需勾选“激进清理（仅保留中文/字母/数字/空格）”。
3. **开始处理**：
   - 点击 **“开始执行清洗”** 按钮。处理期间按钮变为“取消任务”，支持随时中止。
4. **查看结果**：
   - 清洗完成后查看底部日志中的单元格修改统计；
   - 点击 **“打开所在目录”** 或 **“打开结果文件”** 即可直接查看生成的 `_Cleaned` 表格。
